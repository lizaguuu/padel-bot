🎾 Padel-бот: установка в Chrome

Обновление (версия 2): сообщения на немецком, одно сообщение на корт с кнопкой «Buchen».
Если старая закладка уже стоит: нажми на неё правой кнопкой → «Удалить», потом перетащи новую. На странице Playtomic нажми «Stoppen» на чёрной плашке (или обнови страницу) и нажми новую закладку.

  1. Включи панель закладок: Cmd + Shift + B.
  2. Перетащи синюю кнопку мышкой на панель закладок:

    🎾 Padel-бот

  3. Открой страницу клуба: playtomic.com/clubs/mitte-the-cabrio
  4. Нажми закладку 🎾 Padel-бот. В первый раз она попросит токен бота — вставь его (Cmd+V) и нажми OK.
  5. Справа внизу появится чёрная плашка «Padel-бот работает», а в группе — сообщение «бот запущен». Готово!
Важно: бот работает, пока открыта эта вкладка Playtomic и ноутбук не спит. Удобно держать её в отдельном окне Chrome. После перезапуска Chrome или обновления страницы — просто снова нажми закладку (токен уже запомнен).

Не получается перетащить? Нажми , затем в Chrome: Cmd+Shift+O → ⋮ справа вверху → «Добавить закладку» → имя «🎾 Padel-бот», в поле URL вставь скопированное.
